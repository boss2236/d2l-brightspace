d2l commands

Every command in the Brightspace reader, what it does, and when to use it. Run them from the d2l-brightspace/ folder. Only reads your data. Nothing ever gets submitted. To connect an AI or n8n, see Connect your AI.

Daily use

# once: keep it fresh automatically (08:00, 14:00, 20:00)
uv run d2l schedule install

# any time
uv run d2l due          # what's coming up
uv run d2l new          # what changed
uv run d2l ui           # the dashboard
  1. The timer runs sync three times a day. Each run pulls this term from Brightspace, downloads new course files and sends a notification for anything new.
  2. Everything else (due, new, search, the dashboard, AI tools) reads the local database, so it's instant and works offline.
  3. When the session expires you get a notification. Run uv run d2l login once to fix it.

Commands

synctalks to Brightspace

Pulls this term's courses through Brightspace's own API: announcements (full text), grades by category, assignments with submission status, quizzes, calendar and the content tree. It downloads new or changed course files (PDF, DOCX, PPTX, HTML; videos are skipped) and extracts their text. Changes are recorded and sent as notifications. Requests go one at a time, about a second apart. The first run only records a baseline, so you aren't flooded with "new" alerts. dump is an older name for the same command.

uv run d2l sync
uv run d2l sync --show-browser     # watch it work
uv run d2l sync --no-files --quiet # quick refresh, no downloads, no alerts
FlagEffect
--scope currentThis term's courses only (default)
--scope academicEvery course offering, all terms
--scope allAlso Student Services, Self-Help and Employment pages
--no-filesSkip downloading course files
--quietRecord changes but don't notify
--show-browserVisible window instead of headless

dueoffline

Lists everything dated ahead: unsubmitted assignments, quizzes closing and calendar events, in your local time.

uv run d2l due
uv run d2l due --days 30 --course chem

newoffline

The change feed: new announcements, grades, assignments, quizzes, files and due-soon reminders.

uv run d2l new
uv run d2l new --days 30

searchoffline

Full-text search across announcements, assignments, grade items, content titles and the text inside lecture notes and handouts. Each result shows the id to pass to read.

uv run d2l search chain rule
uv run d2l search density --course chem1011

show · readoffline

show prints stored data as a table, or as JSON with --json. read prints a course file's extracted text; get downloads a file, including videos and images the sync skips, and prints its path. In the app, the Files tab does the same: click a file to open it, or use ↓ Download.

uv run d2l show courses
uv run d2l show grades --course math1030
uv run d2l show assignments --open
uv run d2l show files --course chem1010
uv run d2l read 4026138          # id from `show files` or `search`
uv run d2l get 3972581           # download one file (videos too) and print where it is

The Assignments tab shows instructor feedback: the comment, the rubric score for each criterion, and feedback files. Scanned PDFs are read with OCR when tesseract and pdftoppm are installed, so their text is searchable too.

uioffline

Builds dashboard.html, a single offline file. It has upcoming deadlines, a card per course, and tabs for what's new, announcements (click to read in full), grades by category, assignments and course files.

uv run d2l ui
uv run d2l ui --no-open

appthis computer only

The dashboard as a live app at http://127.0.0.1:8766. Its Connect AI tab turns the public link for claude.ai and ChatGPT on or off and copies it, adds the connector to AI apps on this computer, and has Sync now and Log in again buttons. schedule install --serve keeps it running and adds a Brightspace entry to your app launcher.

uv run d2l app --open
uv run d2l schedule install --serve   # always on + launcher entry

mcp · serveoffline

mcp is the MCP server over stdio; AI apps start it themselves. serve runs MCP over HTTP plus a REST API on 127.0.0.1:8765, behind a token, for n8n, custom apps and web AIs. Setup for every client is in Connect your AI.

claude mcp add -s user brightspace -- uv run --directory "$PWD" d2l mcp
uv run d2l serve                  # http://127.0.0.1:8765/mcp and /api/*

semestra

Hands your grades to Semestra, a grade planner. export prints the JSON its Import page accepts, with notes about anything adapted on stderr. push sends every course to your Semestra connector; once it's set up in the app, this also happens after each sync.

uv run d2l semestra export --course MATH1030 > math.json
uv run d2l semestra push
uv run d2l semestra status

token

Shows or replaces the API token that protects the REST API, HTTP MCP and the public link. Replacing it immediately breaks old connector links and n8n credentials. The app's New token button does the same.

uv run d2l token --rotate

notify

sync sends notifications by itself. This command checks your channel setup or re-sends anything still pending.

uv run d2l notify --test         # a test message to every configured channel
uv run d2l notify                # send anything still pending

schedulesystemd user timer

Runs sync automatically using what your OS provides: a systemd user timer on Linux (no root, up to 10 minutes of random delay, catches up after sleep), launchd on macOS, or Task Scheduler on Windows.

uv run d2l schedule install                       # 08:00, 14:00, 20:00
uv run d2l schedule install --times 07:30,19:00   # your own times
uv run d2l schedule install --serve               # also keep the app (dashboard, MCP, REST) running
uv run d2l schedule status
uv run d2l schedule remove

login · courses · reindex

login opens a browser for the normal UDST sign-in (SSO and MFA) and saves the session. The script never sees your password. courses --all lists every enrolment live and labels why hidden ones were skipped. reindex re-extracts text from files already downloaded, without contacting Brightspace.

uv run d2l login
uv run d2l courses --all
uv run d2l show courses --archived   # past terms are archived, not deleted
uv run d2l reindex

First-time setup

cp .env.example .env              # then set D2L_BASE_URL
uv sync
uv run playwright install chromium
uv run d2l login
uv run d2l sync

Settings (.env)

VariableMeaning
D2L_BASE_URLYour Brightspace host, e.g. https://d2l.udst.edu.qa (required)
D2L_TZTime zone for dates, e.g. Asia/Qatar (default: this computer's)
D2L_COURSE_CODE_REGEXOnly course codes matching this count as courses, if your school dates its service pages too
D2L_COURSES_INCLUDE, D2L_COURSES_EXCLUDECourse ids (from d2l courses --all) to always show or always hide
D2L_OCR, D2L_OCR_LANG0 turns OCR off; languages for tesseract, e.g. eng+ara
SEMESTRA_URL, SEMESTRA_KEYSemestra connector address and key (set them in the app)
D2L_SSO_BUTTONLabel of your login page's SSO button (a regex), if the automatic re-login doesn't find it
D2L_NOTIFY_DESKTOP0 turns off desktop notifications
D2L_TELEGRAM_TOKEN, D2L_TELEGRAM_CHATTelegram bot token and your chat id
D2L_DISCORD_WEBHOOKDiscord channel webhook URL
D2L_WEBHOOK_URLWhere each sync POSTs its change batch (n8n, custom apps, WhatsApp bridges)
D2L_API_TOKENBearer token for serve. Generated on the first run
D2L_PUBLIC_HOSTSExtra hostnames serve accepts, e.g. a tunnel's

Troubleshooting

You seeDo this
"Session expired" (terminal or notification)uv run d2l login
"another sync is already running"Wait for it; the timer may be running one
A course is missingRun d2l courses --all. If its term dates don't include today, it's filtered out. Use sync --scope academic
A file shows "missing on Brightspace"The file is broken on Brightspace itself; the browser gets a 404 too. It often exists in another section
A PDF's text says "mostly images"It's a scan or handwriting, so open the file itself
Timer runs but nothing happensjournalctl --user -u d2l-sync -n 50
Something returns empty after a Brightspace updateAn endpoint moved. Check NOTES.md, then DevTools → Network, then update src/d2l/api.py

Keep it gentle: three syncs a day is plenty. Heavy automated access is what gets accounts flagged.
